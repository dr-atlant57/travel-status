# Цифровая Экосистема TRAVEL-РЕСУРСОВ

Премиальный технологический каркас и высококонверсионная сквозная воронка для масштабирования международного клуба **MWR Life** и платформы **Travel Advantage**.

---

## ⚡ Структура и Архитектура репозитория

Проект развернут на базе отказоустойчивой инфраструктуры **GitHub Pages + Cloudflare DNS**. Архитектура папок выстроена для обеспечения чистых, статусных URL-адресов без технических расширений (`.html`):

*   `/index.html` — Главная флагманская посадочная страница. Каскад из 32 экранов, уничтожающий розничные манипуляции рынка и вовлекающий в оптовую модель.
*   `/шок-контент/index.html` — Выделенный триггерный шлюз. Закрытый блок с жестким маркетинговым крюком, бьющий по FOMO-эффекту аудитории.
*   `/CNAME` — Служебный файл конфигурации для связки с персональным доменом.

---

## 🛠 Технологический стек

*   **Frontend:** Чистый, ультра-легкий семантический HTML5 / CSS3 (без тяжелых библиотек и фреймворков для мгновенной загрузки в мобильных сетях).
*   **Шрифты:** Элитарный геометрический гротеск *Manrope* через Google Fonts.
*   **Инфраструктура:** 
    *   **GitHub Pages** — хостинг исходного кода.
    *   **Cloudflare** — проксирование трафика, защита от DDoS, сквозное SSL-шифрование и оптимизация отдачи контента.
